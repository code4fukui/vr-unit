# vr-unit

1ビットからクエタバイトまでのデータ容量単位のスケールを可視化する、A-Frameを使用したVR体験です。

## デモ

- [bit-GB / ビットからギガバイト](https://code4fukui.github.io/vr-unit/)
- [GB-EB / キロバイトからエクサバイト](https://code4fukui.github.io/vr-unit/#2)
- [PB-QB / エクサバイトからクエタバイト](https://code4fukui.github.io/vr-unit/#7)

## 特徴

- **3D可視化**: 12種類のデータ単位（bit、byte、kbyte... Qbyte）を、段階的に大きくなる立方体として表現します。
- **スケーラブルな表示**: URLのハッシュパラメータ（`#0`、`#2`、`#7`）を使用して「ズームアウト」し、より大きな単位の途方もないスケールを理解しやすくします。
- **VRおよびデスクトップ対応**: 没入型のVR環境、または標準的なデスクトップブラウザで閲覧できます。
- **軽量**: A-FrameとVanilla JavaScriptで構築されており、インストールは不要です。

## 閲覧方法

1. **デモリンクを開く**: 上記のリンクのいずれかをクリックして起動します。
2. **操作方法**:
   - デスクトップでは、クリックしてドラッグすることで周囲を見渡せます。
   - VRヘッドセットでは、WebVR対応ブラウザでURLを開くことで没入型の体験が可能です。
3. **スケールの変更**: URLのハッシュ内の数字（例: `.../vr-unit/#7`）を変更して、表示スケールを変更します。この数字は10の累乗の除数として機能し、実質的にカメラをズームアウトして、より大きな単位をフレーム内に収めます。

## 技術的な注意点

この可視化では、スケールを表現するために簡略化された進行を使用しています。サイズは`bit`から`byte`で2倍になり、その後の各SI接頭辞（キロ、メガ、ギガなど）ごとに10倍ずつ大きくなります。
